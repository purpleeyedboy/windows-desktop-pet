# Desktop Pet V2.1 Hunger Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use test-driven-development, verification-before-completion, and the applicable desktop-pet Skills. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an independently owned, persistent integer hunger system and interruptible hunger-animation state machine, plus a separately gated Windows test build.

**Architecture:** `hunger.py` is the sole owner of hunger value, elapsed-time accounting, thresholds, persistence, and idempotent reward application. `hunger_animation.py` maps that state to interruptible presentation phases without changing approved image assets or motion-rig geometry. Runtime wiring injects UTC and monotonic clocks and exposes simulation only when an explicit test-build flag is present.

**Tech Stack:** Python 3.11, integer micro-units, UTC Unix seconds, JSON, atomic `os.replace`, pytest, PyInstaller, PowerShell, GitHub Actions.

## Global Constraints

- Start from current HEAD; do not switch to an older branch.
- Do not change approved cat head, body, eyes, Alpha, head-neck, eye-follow, angles, or golden images.
- Hunger is the only hunger-state owner; no feeding, file receive/delete/recycle, ears, forelimbs, licking, or drag/drop.
- Tests use only pytest temporary paths and injected clocks, never real user files.
- Windows build output is exactly `桌面宠物_饥饿值与饥饿动画.exe` and Windows acceptance remains a separate gate.
