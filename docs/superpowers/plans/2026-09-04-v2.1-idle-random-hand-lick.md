# V2.1 Idle Random Hand Lick Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use test-driven-development, verification-before-completion, and the applicable desktop-pet repository and Windows-release Skills. Steps use checkbox syntax for tracking.

**Goal:** Add one deterministic, interruptible, non-blocking idle state machine for random left/right hand licking and ship it as an independently named Windows candidate.

**Architecture:** Keep the approved renderer, imagery, eye/head motion, Alpha, and minimum-jerk code unchanged. A pure-Python `IdleLickMotion` owns idle qualification, random side/count selection, bounded per-lick phases, interruption, clock-discontinuity recovery, and neutral restoration; the existing coordinated runtime pulse only samples it and arbitrates higher-priority input. A separate PyInstaller spec/build/workflow produces and verifies the one authorized candidate without replacing prior artifacts.

**Tech Stack:** Python 3.11+, pytest 8, Tk `after`, Pillow 11, PyInstaller 6, PowerShell, GitHub Actions.

## Global Constraints

- Start from `c3b218df9dd0cfc84d96231701e771f0382388e1`; do not switch to an older branch.
- Do not change approved cat head/body/eye assets, Alpha, head-neck deformation, eye following, tilt angles, or minimum-jerk behavior.
- Idle qualification uses the V2.1 document's two-second stable-target window (`width < 0.02`, `height < 0.02`) and randomized 25–70 second idle interval.
- Each round chooses left or right and exactly 3–20 licks, inclusively; no ears, dual forelimbs, hunger, drag/drop, feeding, or real user-file handling.
- Direct pointer interaction and higher-priority actions interrupt at the current safe phase boundary, with exact neutral restoration after success, interruption, or internal failure.
- Production randomness is system-backed; tests may inject a seeded RNG.
- Candidate filename is exactly `桌面宠物_空闲随机舔手.exe`.
