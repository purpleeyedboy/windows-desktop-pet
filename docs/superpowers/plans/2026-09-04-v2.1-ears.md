# Desktop Pet V2.1 Independent Ears Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use test-driven-development, Ponytail, verification-before-completion, and the applicable desktop-pet motion, visual-QA, repository, and Windows-release skills. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship an independent V2.1 candidate that adds only separate, pixel-precise left- and right-ear press/hold/release feedback to the approved baseline.

**Architecture:** Derive immutable per-ear hit masks from the Alpha of each currently displayed composed frame inside conservative ear polygons, and feed interaction events to a small cancellable ear state machine. Render ear feedback as a local, reversible deformation of that current composed frame; keep approved source bytes and all existing head/eye motion inputs unchanged. Apply the rendered Alpha as the native Windows input region so transparent pixels remain click-through.

**Tech Stack:** Python 3.11, Pillow 11, Tk, Win32 layered windows, pytest 8, PyInstaller 6, PowerShell, GitHub Actions.
