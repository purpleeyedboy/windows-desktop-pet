# V2.1 Common Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use test-driven-development, systematic-debugging, Ponytail, verification-before-completion, and the desktop-pet repository Skills. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add testable, non-visible common interaction/state infrastructure and a single Windows foundation artifact without changing approved visuals or motion.

**Architecture:** Add independent, UI-neutral Python modules for injected sources, action ownership, release configuration, atomic persistence, and platform/input geometry. Existing rendering and animation paths remain untouched. Package the existing application under the new artifact name while exposing immutable build metadata through the foundation API.

**Tech Stack:** Python 3.11+, pytest 8, Pillow 11, PyInstaller 6, PowerShell, GitHub Actions.

## Global Constraints

- Stay on the current V2.1 starting commit; do not change head-turn angles.
- Preserve approved cat head, body, eyes, Alpha, head/neck, eye-follow, and minimum-jerk behavior and bytes.
- Do not implement visible ears, forelimbs, hand licking, hunger, drag/drop, or feeding behavior.
- Tests must use injected clocks/RNG and temporary persistence paths, never real user files.
- Debug state/time injection is allowed only in test builds or with an explicit debug switch.
- Windows build, hosted Actions evidence, and real-desktop visual acceptance remain distinct gates.
