# Windows 桌面宠物设计规格

## 目标

使用用户提供的写实猫咪照片制作一个 Windows 桌面宠物。交付物必须可以直接双击 EXE 运行，无需用户安装 Python。桌宠保持原猫的脸型、橘白毛色、绿色眼睛和项圈等身份特征。

## 技术路线

- 使用 Python 3、PySide6 实现透明桌面窗口和交互。
- 使用 PyInstaller 生成 Windows EXE。
- 使用原始照片作为身份基准，生成三组写实逐帧动作素材。
- 素材先经过透明背景、统一画布、边缘净化和动作预览检查，再接入程序。

不采用 Electron，避免过大的运行体积；不采用 WPF，以减少透明动画和资源打包的额外实现成本。

## 视觉素材

原始输入为用户提供的猫咪照片。开始实现时将其复制到项目的 `assets/source/`，保留原文件不做覆盖。

第一版动作集：

1. 跳跃：6 帧，包含蓄力、起跳、腾空、下落和落地回稳。
2. 压扁回弹：6 帧，包含下压、最大压缩、过冲拉伸和恢复。
3. 左右抖动：6 帧，以身体和头部轻微左右摆动为主，不改变猫咪身份。

所有帧使用相同尺寸、中心线和脚底基准。角色四周保留少量透明安全边距，不包含文字、气泡、阴影、地面或独立特效。若生成结果出现脸部、毛色、眼睛、项圈或身体比例漂移，只重新生成失败的动作组。

先生成三组动作预览图并进行视觉检查；身份一致、无裁切、无残留背景后再接入程序。

## 窗口与交互

主窗口透明、无边框、不显示在任务栏，默认始终置顶。默认角色高度约 280 像素，首次显示在主屏幕右下区域，并确保整体位于可用桌面范围内。

- 左键按住并移动：拖动桌宠。
- 左键按下和释放的位移未超过点击阈值：视为点击，按固定顺序轮流触发跳跃、压扁回弹、左右抖动。
- 动画播放期间忽略新的动作点击，拖动仍保持可用。
- 鼠标滚轮：以固定步长缩放，角色高度限制在 120 至 520 像素之间。
- 右键菜单：小、中、大三档尺寸；“始终置顶”勾选开关；退出程序。

窗口缩放或切换动作帧时保持角色脚底位置尽量稳定，避免明显跳位。拖动与点击通过距离阈值区分，防止拖动结束时误触动作。

## 对话气泡

每次动作开始时，从内置中文短句列表随机选择一句，例如“看我起飞！”、“压扁了也能弹回来！”、“今天也要精神满满！”。

气泡为不透明白色圆角矩形，深色文字和细边框，带小尾巴。气泡优先放在角色上方；空间不足时放到左侧或右侧。气泡与角色主体之间保留间距，并根据当前屏幕可用区域自动调整位置，不遮挡角色，也不越出屏幕。显示约 1.8 秒后自动隐藏。

## 组件边界

- `PetWindow`：透明窗口、拖动、滚轮、右键菜单和屏幕边界处理。
- `AnimationController`：动作轮播、帧计时、播放锁和脚底锚定。
- `BubbleWidget`：气泡绘制、随机文本、定位和自动隐藏。
- `AssetLoader`：内嵌资源加载、帧缩放缓存和缺失资源错误处理。
- `main`：应用启动、单实例生命周期和未捕获错误记录。若程序已在运行，第二次启动立即退出，不再创建另一只桌宠。

图片资源通过 Qt 资源或 PyInstaller 数据资源随 EXE 分发。程序不得依赖原始临时图片路径。

## 错误处理

- 资源缺失或损坏时显示简短错误对话框并安全退出，不留下不可见后台进程。
- 缩放值始终钳制在允许范围内。
- 置顶状态切换后恢复窗口可见性和当前位置。
- 多显示器环境中使用桌宠所在屏幕的可用区域计算气泡和边界。

## 验证与验收

自动检查：

- 所有动作帧存在、尺寸一致且包含透明通道。
- 透明边缘不存在大面积白底残留。
- 动作顺序、尺寸钳制、对话随机选择和菜单命令可由单元测试覆盖。
- PyInstaller 构建成功，EXE 中包含全部资源。

人工检查：

- 双击 EXE 可以直接启动。
- 桌面透过角色外区域可见，窗口无边框且默认置顶。
- 拖动不误触动作；连续点击按顺序播放三种动作。
- 气泡不透明、不遮挡角色、不越出屏幕。
- 滚轮、小中大菜单和置顶开关均有效。
- 退出后进程结束。
- 三组动画中的猫保持与原图一致，无明显换脸、毛色漂移、裁切、尺寸跳变或白边。

## 交付结构

- `dist/桌面宠物.exe`：可直接运行的最终程序。
- `README.md`：运行方式、交互说明和重新构建命令。
- `assets/`：原始参考图、透明基准图和动作帧。
- `src/` 与 `tests/`：程序源码和测试。
- `build.ps1`：可重复执行的构建脚本。
