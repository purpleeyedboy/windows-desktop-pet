# PAWS rework — 2026-09-10

Base: PR #10, `31362f4c740e313f9389546f9dd55b468c5358b9`.

## Implemented

- Default and packaged pointer displacement increased from 14 / 8 / 28 to
  35 / 20 / 70 physical pixels (nominal / minimum / maximum).
- Existing monitor and ClipCursor boundaries, manual takeover and cancellation
  remain authoritative. The displacement is the total gesture, not per frame.
- Added `tools/import_full_paw_frames.py`: 13 full-cat intermediate RGBA PNGs per
  side, 512x768, byte-preserving import. Two timeline endpoints use the default.
- New full-cat encoding replaces the entire canonical image; it does not crop
  forelegs or feather them onto the baseline. Hash, size, transparency and
  canvas-edge validation runs before writing the imported pack.

## Evidence and remaining gates

- TDD: four displacement regressions failed before code changes; packaged
  configuration regression failed before JSON change; full-cat loader and
  importer tests failed before implementation.
- Focused verification: 25 passed (Pillow deprecation warnings in existing code).
- Approved PNGs and existing generated animation pack are unchanged.
- Existing import_generated_paw_frames.py explicitly produces local replacement
  patches and feathers them onto the body: this matches the reported color seam
  mechanism. Retained only for old-pack reproducibility, not the new art path.
- NOT COMPLETE: new visual assets, full-cat proportions, stationary limb width,
  fur color, exposure, temporal smoothness, Windows interaction, user acceptance.
- Current build therefore remains an old-animation candidate with new movement,
  not a visually repaired animation release.
