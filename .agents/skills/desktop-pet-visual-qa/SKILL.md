# Desktop Pet Visual QA

1. Hash approved source and runtime assets before and after work.
2. Never regenerate or retouch approved images without explicit authorization.
3. Keep automated pixel/Alpha checks distinct from visual judgment on a real Windows desktop.
4. For perceptible visual changes, preserve reproducible previews and inspect at native and enlarged scale.
5. Mark user acceptance pending until the user checks the actual Windows artifact.
