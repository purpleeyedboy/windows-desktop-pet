# 桌面宠物仓库总控

所有未来功能任务必须先使用 `.agents/skills/ponytail` 控制范围，并按工作内容使用现有项目级 Skill，禁止绕过测试与状态门禁：

- 仓库状态、规格、基线或跨模块协调：`desktop-pet-repo-controller`。
- 眼球、眨眼、头颈连续形变、倾斜或其他运动参数：`desktop-pet-motion-rig`。
- 图片、Alpha、接缝、预览证据或人工视觉验收：`desktop-pet-visual-qa`。
- PyInstaller、PowerShell、Windows Actions、EXE、哈希或交付：`desktop-pet-windows-release`。

行为修改必须使用 `test-driven-development`；出现失败必须使用 `systematic-debugging`；提交或发布前必须使用 `verification-before-completion`。这些 Skill 是工作方法，不代表 Windows 实机视觉验收已经完成。
